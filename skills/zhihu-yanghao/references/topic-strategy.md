# 选题策略与心智定位（zhihu-yanghao v1.1.0）

> 选题决定账号人设与流量质量。v1.1.0 起改为**全局话题池 `topic_pool` + 三班轮转**模式，话题完全用户自定义（在 `config.json` 里改）。

## 账号心智定位模板
- 一句话定位：你的账号在知乎代表什么（例：「趣味历史 + 人文心理学」）。
- 人设画像：年龄 / 职业 / 视角（例：40 岁、财务产品背景、理性克制不从众）。
- 禁区：不与前排情绪化回答撞车；不写零流量冷门老问题（除非是热榜窗口期相关）。
- ⚠️ **连续两天错峰**：即便同主线（如「情感」），相邻两天也要换**子方向**（8/11 代际父子一孩视角 → 8/12 切中年女性职场 vs 家庭抉择），避免账号人设指纹连续同质被风控盯上。

## 全局话题池 + 三班轮转（当前默认方案）
在 `config.json` 的 `topic_pool` 放你想养的所有话题（数组），`run_shift.js` 按班次自动轮转，**用户不用管哪天写什么**：

- 轮转算法：`base = 日序号(dayOfYear) + 班次偏移(morning=0/noon=1/evening=2)`；每班取 `pool[base%n]`、`pool[(base+1)%n]`、`pool[(base+2)%n]` 三个关键词去热榜扫。
- 效果：同一天三班各写不同话题方向（早/中/晚错位），跨天自然轮换，避免单一人设指纹，又无需手动维护三线权重。

```json
"topic_pool": ["历史","神话","西游记","情感","心理","代际","社会热点","职场","产品","财务"]
```

想换话题：直接改 `topic_pool` 即可，下次运行自动生效。

## 旧版三线模型（参考，已并入池化）
早期按权重分配：主线 B 端产品/架构 50%、辅线趣味历史 30%、辅线人文心理/代际 30%。现改为池化后，把这几类都丢进 `topic_pool` 即等效，且更灵活。

## 选题来源（按优先级）
1. **热榜窗口期**（最高权重）：`run_shift.js` 默认扫 `https://www.zhihu.com/hot` 前 25 条，命中轮转关键词的中热度话题（例：「在取经路上假如唐僧去世，谁会做第二任领导？」129 万热度，借西游记做能力 vs 制度授权分析）。
2. **话题精华区**：`/topic/19551077/top-answers`（按赞同排序的回答聚合），找可切入角度。
3. **搜索高赞低答**：每 3 天搜方向关键词，找「高赞低答」的冷门好问题（zhihu-cli：`search zhihu`）。
4. **QID 覆盖**：想定点某问题，直接 `SHIFT=xxx QID=xxx ...` 跳过自动选题。

## 回答风格要点
- 理性角度切入，避开前排情绪化 / 搞笑向。
- 字数 250–800 字，段落用 `\n\n` 分隔（fillInput 保留格式）。
- 不自带模板腔；可结合自身职业视角（如财务产品 / 团队管理）增加真实感。
- 发布时段：早班 07:50 / 午班 12:30 / 晚班 20:00（天然分散，合规）。

## zhihu-cli 赋能（可选，数据侧无风控风险）
- `hot --limit 20`：每日扫热榜找窗口期话题。
- `search zhihu`：每 3 天搜方向关键词找冷门好问题。
- `me contents --sort like_count --desc`：每周日全量拉取做数据复盘（对比增量）。
- CLI 走官方 API（无风控），ego-browser 负责行为侧（发布 / 点赞）。
