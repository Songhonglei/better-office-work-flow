# 选题策略与心智定位（zhihu-yanghao）

> 选题决定账号人设与流量质量。以下为可移植模板，按你自己的账号人设调整。

## 账号心智定位模板
- 一句话定位：你的账号在知乎代表什么（例：「趣味历史 + 人文心理学」）。
- 人设画像：年龄 / 职业 / 视角（例：40 岁、财务产品背景、理性克制不从众）。
- 禁区：不与前排情绪化回答撞车；不写零流量冷门老问题（除非是热榜窗口期相关）。

## 三线模型（推荐，基于全量数据诊断）
每日 1 回答，按以下权重分配选题方向：
- 🥇 **主线 50% · B 端产品 / 架构**：专业标签，收藏率高（长尾流量）。适合工作日（周一 / 五）。
- 🥈 **辅线 30% · 趣味历史**：心智标签。改策略不丢方向——**专找热榜窗口 + 热点引发的历史视角**，不再埋头写冷门老问题。走「热榜窗口期话题 → 西游记 / 八仙 / 神话细节解读 → 当下热点引发的历史对比」。
- 🥉 **辅线 30% · 人文心理 / 代际情感**：心智标签。搜索高频方向如「中年社交减法 / 断舍离」「代际沟通」。
- 🚫 放弃的不是历史类本身，是「写零流量冷门老问题」的低效策略。

## 简化备选：日期奇偶轮换（轻量方案）
若不想维护三线权重，用每日 1 回答 + 日期奇偶轮换：
- 单数日 → 情感 / 人文类。
- 双数日 → 趣味历史类。
- 每天跨类目轮换，避免单一人设指纹。

## 选题来源（按优先级）
1. **热榜窗口期**（最高权重）：`https://www.zhihu.com/hot` 扫前 25 条，命中历史 / 心理 / 社会关键词的中热度话题（例：「在取经路上假如唐僧去世，谁会做第二任领导？」129 万热度，借西游记做能力 vs 制度授权分析）。
2. **话题精华区**：`/topic/19551077/top-answers`（按赞同排序的回答聚合），找可切入角度。
3. **搜索高赞低答**：每 3 天搜方向关键词，找「高赞低答」的冷门好问题（zhihu-cli：`search zhihu`）。

## 回答风格要点
- 理性角度切入，避开前排情绪化 / 搞笑向。
- 字数 250–800 字，段落用 `\n\n` 分隔（fillInput 保留格式）。
- 不自带模板腔；可结合自身职业视角（如财务产品 / 团队管理）增加真实感。
- 发布时段：12:00–12:30 或 20:00–20:30。

## zhihu-cli 赋能（可选，数据侧无风控风险）
- `hot --limit 20`：每日扫热榜找窗口期话题。
- `search zhihu`：每 3 天搜方向关键词找冷门好问题。
- `me contents --sort like_count --desc`：每周日全量拉取做数据复盘（对比增量）。
- CLI 走官方 API（无风控），ego-browser 负责行为侧（发布 / 点赞）。
