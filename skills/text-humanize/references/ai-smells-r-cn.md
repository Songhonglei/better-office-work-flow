# 第六类：修辞与抒情信号 (Rhetoric / Lyrical) — R-CN1~R-CN6

> **加载条件：** 体裁闸门判定为**文学**档，或任何呈现抒情特征的文本——**含短文本里的抒情短句**（九个字的 `黄昏，大地温柔的信使` 同样要查，见 SKILL.md Edge Cases）。短文本常规审计不加载本文件。
> **适用范围：抒情散文、唯美文案、公众号美文、散文式长答、现代诗短句。**
> 严肃文学 / 小说 / 议论文**不适用**本类的「写法」建议 —— 但 **R-CN6（抒情无落点）对所有体裁都成立**。
>
> **核心判断原则：用了抒情同位语 ≠ AI 写的。模板化滥用 + 无个人化体验 = 高度疑似 AI。**
> 正反对照例句库见同目录 `lyrical-appositive.md`；前五类信号与中文平台规则见同目录 `ai-smells-cn.md`。

### 先说清「抒情同位语」是什么

指这个结构：

```
本体名词 + 逗号 + [形容词] + 的 + 喻体名词

黄昏，大地温柔的信使
晚风，沉默的叹息
```

常见变体：破折号式（`黄昏——大地温柔的信使`）、内嵌式（`黄昏，这大地温柔的信使，正一寸寸退去`）、独立成句式（`黄昏。大地温柔的信使。`）。

**判定关键从来不是「用没用」，而是三件事：密度、变体、落点。**

### R 类机械自检（先数数，再判断）

本类有两项可以纯统计。**像标点层一样，先出数字、再谈文风** —— 数字比感觉可靠，也方便改完复测。

**① 同位语结构计数**

统计全篇 `X，Y 的 Z` 形态的出现次数，并标出三个量：
- **最长连续句数**：有没有连续 ≥3 句都用该结构（最硬的信号）
- **单段峰值**：单段内最多几个（≥2 即偏高）
- **全篇占比**：占句子总数的比例

⚠️ **已知误判，必须排除：** 朴素的模式匹配会把「主句，动词短语＋的＋宾语」也数进来。实测中
`我站在窗前，想起那些远去的日子` 会被误计为一个同位语。区别在于 —— **真同位语的后半是名词性的，不含谓语动词**。计数时先排掉后半带动词的句子，否则数字虚高（实测同一个样本会从 6 处虚报到 7 处、最长连续从 6 句虚报到 7 句）。

**② 词库命中计数**

- **陈腐喻体词库（核心，清单口径）：** 信使、信笺、叹息、诗篇、守望者、耳语、序章、独白、回响
  扩展嫌疑词（仅作参考，不单独定罪）：呢喃、低语、絮语、乐章、诗行、注脚、剪影、涟漪、褶皱、琥珀、旧梦、坐标、密钥、齿轮、容器
- **万能抒情形容词库（核心）：** 温柔、沉默、浪漫、治愈、漫长、细碎
  扩展嫌疑词：静谧、斑驳、缱绻、绵长、悠远、澄澈、无声、轻轻、悄悄、静静、妥帖
  全篇命中 **≥3 次** → 进入 R-CN4 嫌疑。
- **变体缺失：** 若全篇同位语**清一色是逗号式**，没有一处破折号 / 内嵌 / 倒装变体 → 直接判 R-CN2。

自检输出样例：`同位语 14 处 / 最长连续 4 句 / 单段峰值 3 / 词库命中 9（温柔×3、信使×2、诗篇×2、漫长×2）`

### R-CN1 — 抒情同位语过密

**信号：** 连续 3 句及以上都用「X，Y 的 Z」；或每段至少 2 个，通篇成为句子的「默认格式」。
**为什么被识破：** 真人只在关键意象、情绪落点处用它，其余篇幅靠正常叙述推进。密度本身就是指纹，**不用看内容就能数出来**。
**怎么改：** 全篇留 2-3 处最有力的，其余**改写成叙述** —— 把喻体摊开成动作、场景或对话，而不是换一个喻体接着堆。

### R-CN2 — 句式僵化，无变体

**信号：** 几乎严格遵循「本体 + 逗号 + [形容词] + 的 + [喻体]」一个模板，工整到像填空；不用破折号、倒装、内嵌、省略等松动形式。
**为什么被识破：** 变化是写作者的喘息。**零变体意味着句子是被生成的，不是被想出来的。**
**怎么改：** 把同位语藏进句子中间（内嵌式），或用破折号、括注、独立成句破一破。别让它永远站在逗号右边等形容词。

### R-CN3 — 陈腐喻体

**信号：** 喻体集中在公共文艺词库里：信使、信笺、叹息、诗篇、守望者、耳语、序章、独白、回响……换一篇 AI 文章，命中的还是这批词。
**为什么被识破：** **公共词库 = 可复用的意象 = 没有个人经验的意象。** 真人的喻体带着自己的场景：旧钥匙、煤球炉、旧书包。
**怎么改：** 换成**只能属于这一篇**的东西 —— 你的旧物、你的街区、你闻过的味道。检验法：这个喻体换个作者还能不能用？能用，就说明不够私人。

### R-CN4 — 万能形容词冗余

**信号：** 同位语必挂一个万能抒情形容词：温柔的、沉默的、浪漫的、治愈的、漫长的、细碎的……**删掉形容词后，句子立刻空洞无物。**
**为什么被识破：** 形容词是情绪标签，不是情绪。真人的诗意常靠名词直接碰撞（`故乡，一枚褪色的邮票`），形容词精准而克制，不会每句都加。
**怎么改：** 先删，读一遍。句子塌了 → 那个形容词是撑场面的，得换掉整个喻体；句子立得住 → 本来就多余。

### R-CN5 — 意象不统一

**信号：** 一段内多个同位语各自为政，比如上一句「晚风，沉默的叹息」，下一句「星光，宇宙的信笺」，再下一句「蝉鸣，夏日的弦歌」—— 之间没有共同的情绪或场景内核，只是在换词。
**为什么被识破：** 真人写一段，脑子里有一个场景；AI 写一段，脑子里有一个「文艺感」的模板。
**怎么改：** 每段定一个核心（一个时刻、一种情绪、一个具体地点），所有意象必须能挂到它上面，挂不上的删掉。

### R-CN6 — 抒情无落点 ⚠️ 全体裁适用

**信号：** 通篇只有情绪标签（温柔、治愈、浪漫、怅惘、释然），看不到**具体的人、事、物**触发这些情绪；永远是第三人称全知的「万物皆有诗意」，对自己在意的和不在意的东西用同一种口吻。
**为什么被识破：** 情绪没有来源，就不成立。这一条**唯一不挑体裁** —— 小说、议论文里同样致命，与本参考的 B-CN4（举例论证）、黄金规则 7（个人经验 > 通用道理）同源。
**怎么改：** 给每个抒情句补一个**具体落点**：谁、在哪、什么时候、被什么东西触发的。`旧书包，装过整个暑假的蝉鸣` 之所以成立，是因为它指向一段真的童年。

### 文学体裁快速筛查（条件式，不用计数）

满足以下**任意 3 条**即**高度疑似 AI 生成**：

1. 连续 3 句及以上使用「X，Y 的 Z」抒情同位结构
2. 喻体反复出现通用文艺词（信使、信笺、守望者、诗篇、耳语……）
3. 每句同位语都带「温柔、沉默、浪漫」等万能形容词
4. 意象之间无统一内核，只是华丽辞藻堆砌
5. 通篇只有泛化抒情，找不到具体的个人细节和记忆落点

> **和 🟢🟡🔴 计数评分的关系：**
> 抒情 / 文学体裁**优先用本条件式判定，不优先用 smell 计数**。理由是这类文本「单点致命」：整篇可能只命中 2 条 smell，但恰好是「连续 3 句同位语 + 陈腐词库」，实际已是铁证 —— 计数式会把它误判成 🟢。
> 报告写法：`体裁判定：文学 / 抒情 → 命中 4/5 条 → 🔴 高度疑似`。
