# 抒情同位语 · 正反对照例句库

> 配合 `references/ai-smells-cn.md` **第六类：修辞与抒情信号** 使用。
> 信号定义与判定阈值在主参考里，本文件只做一件事：**给出可以直接比对的好例与坏例**。
>
> **适用范围：抒情散文、唯美文案、公众号美文、散文式长答、现代诗短句。**
> 严肃文学 / 小说 / 议论文**不适用**本文件的「该怎么写」建议 —— 但「有没有个人落点」这一条对所有体裁成立。
>
> 例句来源：团队自用检测清单 + 项目实战改稿。标注作者的诗句未逐条核验原始出处，**作风格参照用**，不作引用依据。

## 一、结构长什么样

```
本体名词 + 逗号 + [形容词] + 的 + 喻体名词
```

变体：

| 变体 | 例 |
|---|---|
| 逗号式（默认模板） | `黄昏，大地温柔的信使` |
| 破折号式 | `黄昏——大地温柔的信使` |
| 内嵌式 | `黄昏，这大地温柔的信使，正一寸寸退去` |
| 独立成句式 | `黄昏。大地温柔的信使。` |
| 无形容词式 | `故乡，一枚褪色的邮票` |

**注意：** 变体本身不是免罪符。四种变体轮着来、但全是公共文艺词库，照样是 AI。变体只能解 R-CN2，解不了 R-CN3。

## 二、反例（AI 味）

**特征：公共喻体 + 万能形容词 + 意象之间无关联。**

```
黄昏，大地温柔的信使。
晚风，沉默的叹息。
星光，宇宙的信笺。
蝉鸣，夏日的弦歌。
落叶，秋天的诗篇。
```

逐条对应的问题：

| 例句 | 命中的信号 |
|---|---|
| 黄昏，大地温柔的信使 | R-CN3（信使）+ R-CN4（温柔） |
| 晚风，沉默的叹息 | R-CN3（叹息）+ R-CN4（沉默） |
| 星光，宇宙的信笺 | R-CN3（信笺） |
| 蝉鸣，夏日的弦歌 | R-CN3（弦歌）+ R-CN5（与前后不搭） |
| 落叶，秋天的诗篇 | R-CN3（诗篇）+ R-CN5 + 关联只到「秋天」这个公共常识 |

**这五句连排，另外直接构成 R-CN1（连续 ≥3 句）与 R-CN5（意象无统一内核）。**

再看一组典型的「形容词一删就塌」：

```
时光，一条漫长的河。          → 时光，一条河。（塌了）
岁月，一首沉默的歌。          → 岁月，一首歌。（塌了）
老屋，一段温柔的回响。        → 老屋，一段回响。（塌了）
```

塌掉的不是形容词，是**喻体和本体之间本来就没有联结**。

## 三、正例（人味）

**特征：喻体私人化、场景化，形容词克制或干脆不用。**

| 正例 | 好在哪里 |
|---|---|
| `落叶，这清凉宇宙的女友` | 「清凉」不是万能形容词，是**触觉**；「宇宙的女友」把落叶提到陪伴关系上，不落俗套 |
| `旧钥匙，生锈的童年口令` | 喻体是**旧物**，不是公共词库里的词；「口令」暗示了记忆的可执行性 |
| `煤球炉，冬天滚烫的心脏` | 指向具体年代的具体器物，有体温 |
| `旧书包，装过整个暑假的蝉鸣` | 「装过」是动作，把静态比喻变成了事件；有明确的时间跨度 |

### 三问快速判定

拿到一个抒情同位语，连问三句：

1. **删掉形容词还剩什么？** 只剩空壳 → R-CN4。
2. **这个喻体换个作者还能不能用？** 能用 → R-CN3（不够私人）。
3. **同一段里所有意象，能不能挂到同一个场景上？** 挂不上 → R-CN5。

三问里中两问，基本可以判 AI。

## 四、实战案例：一个抒情同位语里藏着的事实硬伤

真实改稿案例（短篇《关口》）。原句：

```
这个轧钢机前站三十年、钢花溅脸上不眨眼的汉子
```

问题不是一层，是两层：

1. **R 类问题**：「站三十年」「不眨眼」是刻意突出的苦情修饰，属于用形容词和数字堆出来的「人味」，不是白描。
2. **事实硬伤**：人物 1976 年进厂，故事时间在 1997 年，是 **21 年**，不是三十年。**抒情同位语恰恰是这类错误的常见藏身处** —— 读者的注意力被情绪带走，没人再去算年份。

改法：整句删除。人物的经历按叙事原则拆开，在情节需要时自然带出（《写作原则》第一条：绝不简历式介绍）。

> **审计提示：** 见到「数字 + 形容词 + 的 + 名词」构成的同位语时，除了查 R 类，**顺手核一遍数字**。

## 五、改写示范：把同位语还原成叙述

**改前（AI 味，密集同位语 + 公共喻体 + 无落点）**

```
黄昏，大地温柔的信使。晚风，沉默的叹息。星光，宇宙的信笺。
我站在窗前，想起那些远去的日子。时光，一条漫长的河。
```

**改后（去修辞，落回具体的人、事、物）**

```
天黑得比昨天早了点。楼下收废品的老头还在捆纸箱，绳子绕三道，勒紧，再绕。
我站在窗前，手边那杯水早凉了。
```

改动的不是「更朴素」，而是**把比喻换成事件**：黄昏变成「天黑得比昨天早」这个可观测的事实，信使/叹息/信笺全部退场，情绪由「水早凉了」这种细节承担。

**原则：一次改写只解决一个同位语。** 不要把一个同位语换成另一个更花哨的同位语 —— 那是从 R-CN3 跳到 R-CN3。

---

## 六、改写时的三条红线

1. **不要用新喻体替换旧喻体。** 要改就改成叙述；换词只是掩盖。
2. **不要为了「人味」故意加错别字。** 这是长文/文学体裁，加错字是掉分（见主参考黄金规则 3 的长文降级说明）。
3. **不要留「半吊子」同位语。** 比如把「黄昏，大地温柔的信使」改成「黄昏，大地的信使」—— 形容词删了，公共喻体还在，R-CN3 依旧命中。**要么改成叙述，要么整句删掉。**
