# 风格库 · Style Library

给用过的生图风格起名字。命名之后，以后只说名字或 `style: <slug>`，不必重述整段 prompt 后缀。

- 新增风格往这里追加，按「名字 → 配方 → 可复用后缀 → 后期参数」写全。
- 改了配方，要同步 `SKILL.md` 对应章节。
- 名字一旦用过（写进过文章/存档/对话），**只加不改**；真要改就旧名留作别名。

## 白纸速写 · `paper-sketch`

**一句话**：白纸上一幅钢笔速写——白底黑线，几乎不上灰阶，四周一圈纯白当画框。

| 项 | 内容 |
|---|---|
| 首用 | 2026-09-26，公众号小说配图（1997 北方工厂家庭 / 幽默市井小说） |
| 定位 | 中文文学、纪实、年代题材。**调性不写死在风格里**——靠支柱 4 的情绪词切换：市井小说用「轻松、有戏」，纪实/评论用「沉静、克制、郑重」（两种都实测过，见文末「调性变体」） |
| 底色 | 纯白，不留纸纹、不做旧 |
| 用色 | 只有黑、白 + 极少量灰阶，无任何色彩 |
| 画框 | **可选件**。用户要求时后期加纯白留白边（prompt 求不来）；**默认不加** |

### 四根支柱（**线 / 笔 / 调**缺一就变味；**框**是可选项，默认不做）

1. **线** — 「白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影」。
   只写「简笔线条」不够，模型仍会给大块排线阴影。这一句是「线条感」的开关。
2. **笔** — 「笔触轻快流畅，像钢笔速写」。这一句决定出来是雅致速写还是硬朗版画。
3. **框（可选，默认不做）** — 四周纯白留白边。**prompt 求不来**（2026-09-26 实测：写了「四周留整圈空白」，模型基本不遵守），要加只能后期 `add_frame.py --frame --line 0`。**用户没明确要求留白边，就不加**——留白是审美偏好，不是这个风格的必备件。
4. **调** — 情绪词必须写死，且**要跟着题材换**：
   - 市井/幽默题材 →「明快、松弛、带市井喜感，是一幅俏皮的风俗速写，不阴郁、不悲剧」。
     漏了这句，年代题材默认往沉重、苦情、强对比走（封面曾因此被否）。
   - 纪实/评论/历史题材 →「沉静、克制、郑重，是纪实速写，带一点苍凉，不阴郁、不苦情、不夸张煽情」。
     **关键是后半截「不……不……不……」**：既要拉出厚重感，又要把默认的苦情/煽情压住。
   - 反面教训：**别把情绪词跟风格名绑死**。上一版这里只写了「轻松、有戏」，于是"白纸速写＝轻调"被当成风格属性；其实它只是一组可替换的情绪词。

横向两条硬要求：

- **写实比例 + 年代细节**。抽象要求换成可画的物件：不说「很穷」，说「洗得发白的工作服」「磕瘪的铝饭盒」「虎口一道发白的旧疤」。
- **人物给「标识包」**，五维（脸型骨相 / 五官 / 发型 / 体态 / 标志物），跨图复用同一套措辞；末尾再钉一句「两人的脸型轮廓差异极大，绝不相同」。
  只写「一个方脸一个瘦脸」会塌成同一张脸。详见 `SKILL.md` 表格。

### 统一 prompt 后缀（每张末尾都粘）

```
纯粹黑白线描，白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影；
笔触轻快流畅，像钢笔速写；写实比例与真实的九十年代细节，人物不做美化、
不卡通化，但神态生动有戏。人物和主要物件集中在画面中间，四周留出整圈空白，
人和物件都不许碰到画面边缘，构图像速写本上的一小幅画。画面不出现任何文字、
数字、书法、落款或印章；右下角留出大面积空白，不放置任何主体或细节。
```

> 后缀里仍保留「四周留整圈空白」「右下角留白」——实测不生效，但写上无害，能略微降低出血概率。**真正的留白靠后期**，不要指望 prompt。
> `size` 用标准比例：插图 `1536x1024`（3:2）；封面 `1408x704`（2:1），再裁到目标比例。

### 后期（必做：裁水印；留白边框可选）

```bash
S=scripts/add_frame.py

# 默认：只裁水印，不加框
python3 "$S" in.png out.png --crop-bottom 80
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35                    # 微信头条封面（无白边），再 sips -z 383 900

# 用户明确要求留白边时，才加 --frame
python3 "$S" in.png out.png --crop-bottom 80 --frame --line 0
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35 --frame --line 0  # 留白后恰为 2.35:1
python3 "$S" in.png out.png --crop-bottom 70 --frame --ratio 1 --pad 0.04 --line 0  # 方形次条封面
```

先量水印再裁（见 `SKILL.md`「裁掉右下角水印」）。**加框是可选项**，用户没要求就不加。
一旦要加，`--line 0` 是标准做法：线条画本身已满是黑色轮廓，再加画框线显生硬。
白边取短边 `0.06`；边框色＝底色纯白，所以看不出一圈"框"，只觉得是留白。

### 调性变体 · 沉郁纪实（2026-10-06，《长城》配图实测）

同一套风格，把支柱 4 的情绪词整体替换即可，**其余配方（线/笔/框）一个字不动**。

**替换用的后缀**（在原后缀基础上改两处：年代细节项、情绪词项）：
```
纯粹黑白线描，白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影；
笔触轻快流畅，像钢笔速写；写实比例与真实的物件细节，人物不做美化、不卡通化，神态生动；
调子沉静、克制、郑重，是纪实速写，带一点苍凉，不阴郁、不苦情、不夸张煽情；
人物和主要物件集中在画面中间，四周留出整圈空白，人和物件都不许碰到画面边缘，
构图像速写本上的一小幅画；画面不出现任何文字、数字、书法、落款或印章；
右下角留出大面积空白，不放置任何主体或细节。
```

**实测有效的分镜（《长城》1 封面 + 5 插图）**
`两种下场`（长卷封面：左半博物馆展台上一尊**无头菩萨身躯**+一个极小的人仰看 ｜ 右半山脊上长城被挖开豁口、渣土车穿过）→ `石窟无头`（石壁佛龛内数尊佛像头部位置全空、只剩凿切断面，前景一尊残缺身躯）→ `墙上豁口`（夯土长城拦腰掏开，断面露层理，渣土车从豁口开过）→ `界桩迟到`（**远景**：夯土长城沿山脊蜿蜒入远山，中段壑口堆着碎石，墙顶一个小人影沿墙走远；近处荒草坡上立着一根矮墩墩的水泥界桩）→ `女儿问砖`（城墙顶上九岁女孩仰头按砖、父亲手搭垛口低头看她，长城沿山脊蜿蜒远去）→ `清早守墙`（天蒙蒙亮，老人背蛇皮袋、拄木杖走在长城残墙顶）。

三条可复用结论：

- **素白无字的「竖长物件」要慎用——十有八九被读成「无字碑」**。`界桩迟到` 第一版让界桩素白无字、竖立在画面正中（一个人蹲在旁边），反馈是"看着像一块无字碑"，情绪整个跑偏。改远景后成立：**把桩改成矮胖的方块墩子**（有底盘、斜切顶），素白无字才只是"没写字"，而不是"等着刻字"。
  **形状定调，空白只负责不抢戏。** 想表达"制度立了、执行没到"，靠"新桩 vs 老裂口"的并置，不靠把物件画大。
- **人小、物长 = 尺度对比，靠 prompt 里把比例写出来**。第一版 `女儿问砖` 只说"父女两人都很小，城墙很长"，出来是一段局部墙；改成"**父女两人非常小，长城很长很高，从他俩脚下一路延伸到画面深处和远处的山脊上**"才成立。抽象形容词不够，要给出"延伸到画面深处和远处"这种可画的走向。
- **实测尺寸（可直接核对）**：插图 `1536x1024` → 裁底 80 → **`1536x944`（默认，无框）**；加白边时 `1670x1078`（四周各加 67px = pad 56 + gap 11）。封面 `1408x704` → 裁底 70 → `--ratio 2.35` → **`1408x600`（默认，无框，比值 2.347）**；加白边时 `1496x638`，比值 2.3448（与 2.35 差 0.2%，视觉无感，可接受）。
- **水印实测位置**：`1536x1024` 在 y≈955 起；`1408x704` 在 y≈650 起。裁 80 / 68 后右下角均为纯白，6 张全部验真通过。

### 有效分镜参考

`守门`（长卷封面：女人坐门槛、抱门框、举黄纸符瞪眼嚷，男人在后摊手无奈，门外胡同与摩托）→ `书案台灯`（饭桌摊万年历，女人戴老花镜排八字，男人解着扣子进门）→ `锯末搓手`（男人水管下用锯末搓手、叼着长烟灰，门口探进儿子的头）→ `桥下问卦`（桥洞下戴墨镜的老头转石球，女人蹲在旁边抓布包）→ `一碗寿面`（热气腾腾的锅 + 卧两个鸡蛋的面碗推过去，镜片被哈白）。

**封面要「有戏的场面」，不要实物空镜**。v1 用「闩死的门」做实物隐喻，被评为太阴暗；换成有表情、有冲突的场面后通过。实物隐喻适合正文插图，不适合需要吸引点击的封面。

> **补充（2026-10-06）**：上面这条是**市井/幽默题材**的结论，别当通则。纪实、评论、历史题材的封面可以走
> **「左右两半对照的长卷」**——不用表情冲突，靠两组画面的并置把标题的矛盾直接摆出来
> （《长城》封面：左半展台上无头菩萨身躯 ｜ 右半山脊上被挖开的长城与渣土车）。
> 两条都成立，区别在于**题材要让读者"先看懂矛盾"还是"先被逗住"**。

## 水墨文艺风 · `ink-wash`

**一句话**：淡墨宣纸，留白多，左下角一枚朱砂印。

| 项 | 内容 |
|---|---|
| 首用 | 2026-09-15，历史文化类公众号 |
| 定位 | 历史、文化、人文题材；调性偏静、雅 |

**统一 prompt 后缀**：

```
淡墨为主，古旧宣纸质感，文艺气质，留白多；画面不出现任何文字、题跋或印章字样；
左下角一枚极简朱砂印记；右下角留白，不放置任何元素。
```

**要点**

- 前缀用 4 字场景词（如「葫芦小院」「墙里墙外」），既是防覆盖标记，也让模型先抓住画面主题。
- 调色只允许三种：淡墨 + 极淡赭石/赭黄（暖）+ 一点极淡花青或藤黄（冷/光）。**朱砂只用在左下角那枚印上**。
- 留白要写进正文，不能只写「留白多」。例：「湖面以大片留白化作雾气」「地面留白成刺眼的白光」。
- 人物用「寥寥数笔勾勒」「身形疏淡」，不写面部细节——写意比工笔稳。
- **年代不写死就默认古装**。要现代场景必须点明「现代装束」，否则出来是水墨古装。
- 封面走横向长卷 `1408x704`，裁 `900x383`；内容插图 `1536x1024`。
- 组图与文章走向对齐：**一张封面立主题，其余按小标题顺序各配一张**，不要六张同风格空镜。

**有效分镜**：`北国拆墙`（长卷：北国城郭 ｜ 江南水乡，中间一道墙断开豁口）→ `葫芦小院` → `午门排队` → `西湖无墙` → `墙里墙外`（一道素白高墙横贯，墙外一人仰头看，墙内一人背墙坐）→ `霜降葫芦`。
其中「墙里墙外」这类**用构图直接对应论点**的图，比纯风景插图被引用率高得多。
